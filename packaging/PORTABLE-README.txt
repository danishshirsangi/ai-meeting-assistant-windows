AI Meeting Assistant - Portable Windows x64

Extract ALL files into a writable folder. Double-click AI-Meeting-Assistant.exe.
Keep _internal next to the EXE. No Python or installer required.
Enter your own Gemini API key when prompted. Internet is required for Gemini and the first Whisper model download.
Local data and unencrypted API configuration are stored in data; Whisper cache in models; diagnostic logs in logs.
Do not share your configured folder or sensitive data. Obtain consent before recording meetings.
This executable is unsigned; Windows may show a warning.
